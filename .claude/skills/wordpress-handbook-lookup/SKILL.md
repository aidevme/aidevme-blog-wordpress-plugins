# WordPress handbook lookup

`docs/wordpress/` holds locally synced mirrors of official developer.wordpress.org content. They are the authoritative reference for WordPress APIs and conventions in this repo; check the relevant page before writing code or a spec that touches that area, because memory of WordPress APIs can be stale or subtly wrong.

The mirrors are generated by the `researcher` agent. Never edit them by hand; a stale or wrong page is reported, and refreshed with the matching `/sync-wordpress-*` command.

## Notes

- A page that says its content "moved" or lives in the Common APIs Handbook is expected (several `04-plugin-security/` pages do); the local file already reflects the correct location. Use it as it stands.
- A file that is empty, or whose row in `index.md` has a blank **Last Synced On**, has never been synced. Say so and ask for a sync (for example `/sync-wordpress-plugin-docs 3.1`) instead of filling the gap from memory.
- Custom post types: prefer plain custom tables plus dedicated `WP_List_Table` admin screens when the data is not really "posts". `src/credentials-manager-plugin/SPECIFICATION.md` (the section on superseded designs) records why a CPT approach was abandoned in this repo.
- Code blocks inside the mirror use spaces; PHP in the plugins uses tabs (WordPress core style). Do not cross the two conventions.
- Link to mirror pages with relative links in specs, the way `SPECIFICATION.md` does.
