# Aidevme Blog WordPress Plugins

WordPress plugins developed for the Aidevme Blog project.

## Repository Structure

- `assets/` - Shared plugin assets and supporting resources.
- `docs/` - Project and plugin documentation.

## Status

This repository is being prepared for the initial plugin implementations. Documentation and installation instructions will be added as plugins are introduced.
