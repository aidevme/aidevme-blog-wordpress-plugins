# Nonces

Reference: <https://developer.wordpress.org/apis/security/nonces/>

## Note

This content has moved to the Nonces page in the Common APIs Handbook: <https://developer.wordpress.org/apis/security/nonces/>

Nonces ("number used once") are used to verify that a request originated from the expected source (e.g. a form or link on your site) and to protect against CSRF (Cross-Site Request Forgery). The detailed guidance on creating and verifying nonces is now maintained in the Common APIs Handbook rather than the Plugin Handbook.
