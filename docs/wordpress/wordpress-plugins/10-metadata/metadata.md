# Metadata

Reference: <https://developer.wordpress.org/plugins/metadata/>

## Overview

Metadata is information about information. In WordPress specifically, this refers to data connected to posts, users, comments, and terms.

## Key Characteristics

The platform supports a many-to-one relationship structure for metadata, offering considerable flexibility. Users can attach multiple meta options to a single item and store diverse types of data within this framework.

## Chapter Topics

This section covers three primary areas:

- Managing post metadata
- Creating custom meta boxes
- Rendering post metadata
