# Internationalization

Reference: <https://developer.wordpress.org/plugins/internationalization/>

## Overview

Internationalization is the process of developing a plugin so it can easily be translated into other languages, commonly abbreviated as i18n.

## Significance

Since WordPress serves users worldwide in non-English speaking regions, developers must code text strings in ways that translators can modify without altering source code. This enables localizations — adaptations for specific locales including language and formatting conventions.

## Core Message

While developers may lack resources to provide translations for all users, proper internationalization allows professional translators to localize themes and plugins independently, maintaining code integrity throughout the process.
