# Add Your Plugin to the Block Directory

Reference: <https://developer.wordpress.org/plugins/wordpress-org/add-your-plugin-to-the-block-directory/>

## Overview

WordPress maintains two primary directory listings for block-related plugins:

1. Block-only plugins — containing exclusively blocks
2. Plugins with blocks — larger plugins that include blocks among other features

A plugin can be listed in both, however there is no benefit to a plugin's SEO or ranking due to either.

## Block-Only Plugins

These minimal plugins must meet stricter requirements than standard WordPress plugins. They should stick to mostly JavaScript code and keep PHP to the bare minimum, and not add any UI or other code outside of the Gutenberg editor.

Key requirements:

- Smaller, more minimalist design
- Compliance with standard plugin guidelines
- Single-click installation capability via the Block Editor

Developers can self-submit qualifying plugins using the Block Checker tool, which validates eligibility and manages directory inclusion.

## Plugins Containing Blocks

Larger, more complex plugins like Jetpack or Yoast SEO fall into this category. These combine block functionality with additional features.

Submission process: developers should contact plugins@wordpress.org to request inclusion. The submission requires verification that the plugin meets current guidelines and contains no security vulnerabilities before approval.
