# Alerts and Warnings

Reference: <https://developer.wordpress.org/plugins/wordpress-org/alerts-and-warnings/>

## Overview

WordPress.org plugin pages display several types of alerts to communicate plugin status to visitors and owners.

## Approved and Pending Status

Displayed only to plugin owners, this blue alert indicates that the plugin is approved and awaiting data upload but not yet visible to the public.

## Closed Plugins

Red alerts inform visitors that a plugin has been closed. Plugins closed after January 2018 include closure dates. After 60 days, the notice explains the reason, which may include:

- Author Request
- Guideline Violation
- Licensing/Trademark Violation
- Merged Into Core
- Security Issue

## Out of Date Notice

A yellow warning appears for plugins unsupported on WordPress's last three major releases. Developers receive email reminders before major WordPress releases and only need to update their readme file's "Tested up to" value — no new version release is required.
