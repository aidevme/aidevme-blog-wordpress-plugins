# Compliance Disclaimers

Reference: <https://developer.wordpress.org/plugins/wordpress-org/compliance-disclaimers/>

## Overview

WordPress.org Guideline 9 prohibits plugins from implying that a plugin can create, provide, automate, or guarantee legal compliance.

## Core Requirement

Plugins must clarify that they assist with compliance rather than guarantee it. For example, change "will make your website ADA compliant" to "will help make your website more ADA compliant."

## Main Sections

- Required updates to readme files, documentation, and assets
- Plugin display name changes (e.g., "100% Compliance" becomes "Compliance Assistant")
- Special handling for service-based plugins (clarify responsibility lies with the service)
- Third-party library considerations
- Enforcement: non-compliance results in warnings, then potential plugin closure after 60 days

No plugin can offer 100% legal compliance, and responsibility ultimately rests with site administrators, not developers or their tools.
