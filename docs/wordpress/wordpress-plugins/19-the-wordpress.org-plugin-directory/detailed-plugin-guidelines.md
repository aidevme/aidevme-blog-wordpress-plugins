# Detailed Plugin Guidelines

Reference: <https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/>

## Overview

This page outlines the requirements that developers must follow for plugins hosted on WordPress.org.

## Key Guidelines

Plugins must:

- Be compatible with the GNU General Public License
- Maintain human-readable code without obfuscation
- Avoid trial-ware or artificial feature restrictions
- Obtain explicit user consent before tracking activity
- Not execute code from third-party systems
- Respect user privacy and avoid misleading practices
- Keep administrative dashboards uncluttered
- Use WordPress's built-in libraries rather than duplicating them

## Notable Requirements

All code, data, and images used in a plugin must comply with the GPL or a GPL-Compatible license. Developers bear sole responsibility for their plugin's contents and compliance.

WordPress.org reserves the right to disable, remove, or modify plugins in the interest of public safety if necessary.
