# Plugin Developer FAQ

Reference: <https://developer.wordpress.org/plugins/wordpress-org/plugin-developer-faq/>

## Overview

This FAQ contains extensive guidance across multiple areas of plugin development and directory participation.

## Main Categories

- The Plugins Team (contact information and team membership)
- Submissions and Reviews (detailed submission procedures and timelines)
- Using The SVN Repository (file organization and version management)
- Your WordPress.org Page (plugin directory management)
- Plugin Names (naming conventions and trademark considerations)
- Search (discoverability and ranking)
- The Support Forums (community interaction)
- Closed Plugins (closure procedures and appeals)
- Plugin Ownership (access management and transfers)

## Key Content Highlights

Submission requirements: it's a .zip file and under 10Mb, and must be production-ready — complete, without errors, without unnecessary logs.

Regarding approval timelines, plugins should be approved within fourteen days of initial review if the code is correct.

For plugin naming, developers cannot begin their Display Name with someone else's trademarked or common term, to protect against legal issues. Once a plugin slug is approved, it cannot be renamed, so choose carefully during submission.

Regarding closed plugins: closing your plugin is intended to be a permanent action. You will not be able to reopen it without contacting the plugins team.
