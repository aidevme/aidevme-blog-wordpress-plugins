# The WordPress.org Plugin Directory

Reference: <https://developer.wordpress.org/plugins/wordpress-org/>

## Overview

WordPress.org provides complimentary hosting for plugin developers. The platform enables creators to monitor usage statistics, gather user feedback and reviews, and offer community support through forums.

## Key Benefits

Developers gain access to:

- Usage analytics and performance tracking
- User reviews and feedback mechanisms
- Community-supported forums for assistance

## Core Requirements

Plugins must adhere to several standards:

1. **Licensing** — compatibility with the GNU General Public License v2 or later is mandatory; unlicensed code defaults to GPLv2 or later status.
2. **Repository Use** — the Subversion repository exclusively hosts functional WordPress plugins.
3. **Legal Compliance** — developers must respect intellectual property laws and avoid illegal, unethical, or offensive conduct, including spam and harassment.

All submissions require compliance with the Detailed Plugin Guidelines documentation.

## Getting Started Resources

The platform offers guidance across multiple areas:

- Plugin planning, submission, and ongoing management
- Subversion version control systems
- readme.txt file management
- Plugin headers and asset preparation
- Ownership transfers and takeovers
- Block directory integration
- Security management and reporting procedures
