# Using the Forums

Reference: <https://developer.wordpress.org/plugins/wordpress-org/using-the-forums/>

## Overview

This page addresses how plugin developers should manage their presence in WordPress.org forums and reviews, particularly regarding premium versions and support policies.

## Key Guidelines

**Universal Standards Apply**

The plugin owner is the ultimate controller of the plugin. However, if other developers or support reps violate the guidelines, the plugin is at risk for censure and closure.

**Support Boundaries**

The forums are not commercial spaces. Developers cannot request private contact details, offer to access user sites, or charge for assistance through WordPress.org channels. This protects both parties legally.

**Premium Support Disclosure**

Developers can decline free support if clearly stated in the plugin readme. Conversely, users who purchased premium versions should be directed to dedicated support channels rather than free forums.

**Account Management**

- Multiple accounts per company are acceptable if one serves as owner only
- Personal accounts should handle forum participation
- Shared accounts are prohibited — they create accountability issues and confusion

**Reviews of Premium Tiers**

Users may mention premium features in reviews when the free version promotes the paid option, provided reviews discuss actual functionality rather than serving as harassment or focusing solely on upselling complaints.

## Bottom Line

All participants must follow community guidelines consistently. The platform prioritizes user experience and treats forum members as community members, not customers.
