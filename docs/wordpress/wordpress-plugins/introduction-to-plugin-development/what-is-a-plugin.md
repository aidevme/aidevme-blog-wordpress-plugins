# What is a Plugin?

Reference: <https://developer.wordpress.org/plugins/intro/what-is-a-plugin/>

## Overview

Plugins are packages of code that extend the core functionality of WordPress. They consist of PHP code and may incorporate additional resources like images, CSS, and JavaScript files.

## Purpose and Examples

WordPress plugins enable developers to build upon the platform's existing capabilities. Examples range from a simple plugin that displays recent posts, to a more complex solution such as a support ticketing system with email alerts and customer portals.

## Minimal Requirements

Most WordPress plugins are composed of many files, but a plugin really only needs one main file with a specifically formatted DocBlock in the header. The Hello Dolly plugin demonstrates this principle — a famous early example containing just 100 lines of code that displays song lyrics in the WordPress admin dashboard.

## Opportunity

Plugin authors can reach millions of WordPress users by transforming their ideas into functional code, with the Plugin Handbook available as a development resource.
